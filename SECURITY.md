# Security Policy

## Supported Versions

The following versions of **API Tape** are currently being supported with security updates.

| Version | Supported |
| ------- | --------- |
| v1.6.x  | ✅ Yes    |
| < v1.6  | ❌ No     |

## Reporting a Vulnerability

We take the security of API Tape seriously. If you believe you have found a security vulnerability, please do NOT open a public issue. Instead, follow these steps:

1. Send an email to [me@erdem.work] with the subject "Security Vulnerability Report".
2. Include a detailed description of the vulnerability, including steps to reproduce.
3. We will acknowledge your report within 48 hours and provide a timeline for a fix.

Once a fix is released, we will give credit to the researcher (unless they prefer to remain anonymous).

## Responsible Disclosure

We ask that you follow responsible disclosure principles:

- Give us reasonable time to investigate and fix the issue before public disclosure.
- Do not exploit the vulnerability beyond what is necessary to prove its existence.
- Do not access or modify data belonging to others.
