# Support

Need help with **API Tape**? Here are the best ways to get assistance.

## Documentation

- Check the [README.md](./README.md) for usage, CLI options, and examples.
- Read [CONTRIBUTING.md](./CONTRIBUTING.md) for guidance on contributing to the project.

## GitHub Issues

- If you've found a bug, please [open an issue](https://github.com/laphilosophia/api-tape/issues) using the Bug Report template.
- For feature requests, use the Feature Request template.

## GitHub Discussions

- For general questions, community support, or sharing ideas, visit our [GitHub Discussions](https://github.com/laphilosophia/api-tape/discussions).

## Security

- To report a security vulnerability, please refer to our [SECURITY.md](./SECURITY.md) policy and do not open a public issue.
